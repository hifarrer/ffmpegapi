Privacy Policy

FFMPEG API processes account, billing, API usage, and media-processing request data to provide the service. API requests may include media URLs supplied by users or applications.

Data We Process

  • Account information such as email address and authentication records.
  • API keys, request metadata, endpoint usage, and processing logs.
  • Media URLs, temporary uploaded files, generated outputs, and job status records.
  • Billing and subscription data handled through payment providers.

How Data Is Used

Data is used to authenticate requests, process media jobs, prevent abuse, debug failures, measure usage, and provide billing and support.

Retention

Temporary media files and generated outputs may be deleted automatically. Operational logs and account records may be retained as needed for security, billing, and support.

Contact

For privacy questions, use the contact page.
